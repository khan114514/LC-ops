# 条件扩散蒸馏：Codex 研究交接包

正式研究范围为 **T1 身份保持视频生成、T2 Canny边缘控制图像生成、T3 人体姿态控制图像生成**，三个均须派工与报告。详见 [三任务契约](specs/three_task_protocol.md)。

这是一套交给另一位研究者使用的研究执行材料：启动 prompt、角色 prompts、项目专用 skills、实验规范、状态模板和英文论文 v0。**本包制作没有运行视频训练，也没有产生性能结果。** CDist 只是内部工作名；论文创新性仍需最新文献对照与实验支持。

## 最快使用

1. 把整个目录或 ZIP 交给对方，解压到一个可写的新项目目录，并让 Codex 能访问该目录。不要只发某一个 SKILL.md。
2. 把 [prompts/00_START_HERE_CN.md](prompts/00_START_HERE_CN.md) 的完整内容发给总控 Codex。把其中项目路径替换为对方的实际绝对路径。这个 prompt 包含未来创建/协调项目聊天的授权文本；本次打包没有创建这些聊天。
3. 总控先查环境、模型与预算，创建状态和任务分工，推进能执行的工作。GPU 地址、可用时段、训练预算与数据访问由对方环境决定；凭据不要粘贴进聊天或材料包。
4. 总控按门槛推进工程闭环、机制诊断、128/2048/8192 样本训练、正式评价、泛化实验与论文更新。没有 GPU 时推进文献、CPU toy、代码和协议，视频实验保留待执行状态。

无需安装 skill 也能使用：让 Codex 直接读取包内相应 SKILL.md。如果需要 `$cdist-...` 自动发现，可运行：

```bash
python3 scripts/install_skills.py --destination /你的项目/.agents/skills
```

安装只复制项目技能，不改系统配置、不调用 API、不启动实验。安装器在目标 skill 中补齐相对引用所需的项目资源，因此不用依赖原打包机器的路径。目标已有同名技能时停止，避免覆盖。旧版本宿主若只识别其他目录，使用其实际支持的 skill 目录；无需为此更换模型。重新安装后是否需要新开聊天取决于宿主发现机制。

## 你收到的内容

- `prompts/`：总控入口、共享 worker 契约与各角色提示词；续跑和失败诊断也有独立入口。
- `skills/cdist-*`：面向本研究的操作技能，按角色读取，不一次塞入全部上下文。
- `specs/`：方法、数据、实验矩阵、评价、门槛、图表计划。它们是研究执行的共同依据。
- `project.yaml`、`state/`、`templates/`：可填写配置、共享状态和证据模板，当前实验状态全部为未执行。
- `paper/`：英文研究计划版初稿和 LaTeX 源码。后续真正的论文初稿必须由实测结果驱动更新。
- `literature/`：本次来源核验和引文记录。运行时继续更新，特别是高度接近的 HPSD。
- `vendor/skills/`：可选通用写作与研究构思技能快照，保留来源和许可证。
- `scripts/`：无第三方依赖的预检、技能安装、预算估算和包结构检查；不是视频训练实现。
- `source/original_research_plan_zh.txt`：用户粘贴的完整原方案。原文提到的 22 页 DOCX **没有随本次输入提供**，不能假装已经读过。

## 研究要保留的判断

老师可接收文本，但不接收新增身份参考条件。学生已具有参考身份控制能力。老师生成完整视频后提取参考条件，使用独立重新加噪的配对监督；混合分支遵循老师一步、学生 k 步、在新状态查询与蒸馏。目标修正限制身份代理误差的局部增加。

不要在实现前把这些假设当作结论：原始老师方向是否有最终质量收益；目标修正是否优于门控、弱 KD 和额外条件损失；混合轨迹是否独立优于完整学生轨迹。主实验保留 S0 及八个训练方法，默认三训练 seed；按建议全量协议仅主测试就有 40,000 条视频，预算须用真实完整更新/生成成本估算。

## 交付与论文状态

接收者完成研究时至少应交付：版本锁定的代码与配置、数据划分/许可/过滤记录、全部成功和失败 run 清单、检查点与校验和、逐视频指标、统计脚本、六主图/八补图/三主表的证据映射、复现说明、英文论文 `.tex` 与 PDF、补充材料、独立审稿与修订记录。实际内容依结果和预算收缩，不能以占位文件冒充完成。

ICML 是目标会议，年份尚未指定。包内 2026 模板只是已取得的排版参考；执行时查询目标年份官方规则，不预设下一届页数、截止时间或投稿已完成。公开上传、投稿和采购不包含在研究运行授权里。

目录与各技能的用途见 [SKILL_CATALOG.md](SKILL_CATALOG.md)；首次接管可先读 [AGENTS.md](AGENTS.md)。
