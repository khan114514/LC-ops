# 研究定义与主张边界

三任务范围修订：正式任务为T1身份视频、T2 Canny图像、T3人体姿态图像，见 [three_task_protocol.md](three_task_protocol.md)。本文件原有视频/身份/帧数和40,000视频细节描述T1；图像任务按三任务契约执行，不能套用人脸检测或按视频身份分组来评图像边缘/姿态。

文档状态：研究计划；所有实验结果均**待验证**。本包制作阶段不启动训练、购买算力或提交论文。原文所指 22 页 DOCX 未包含在已提供文件内，本规范依据用户实际提供的粘贴文本；不能声称已核对该 DOCX。所有数量与超参数是建议起点，正式值须写入冻结配置。

## 问题与对象

主任务：外部人物参考图 `c` 与动作文本 `b` → 条件学生独立生成视频。老师 `T(z,t,b)` 冻结，不接收新增身份条件 `c`；它可接文本，因此不得简写成完全无条件模型。学生 `Sθ(z,t,b,c)` 从已有身份控制学生 `S0` 开始。本研究衡量质量、动作与稳定性的改善，并预设身份及动作非劣约束。

主平台候选是 Wan2.1-T2V-1.3B → Concat-ID-Wan-AdaLN；第二平台候选是 CogVideoX-5B → ConsisID；这些是需核验的适配方案，不能直接假定 checkpoint、VAE、scheduler 与许可兼容。首帧 I2V 只作辅助任务；固定首帧不进入身份或生成区域评分。第二条件任务候选为同基础模型的 T2I 老师与 Canny-ControlNet 学生。论文目标为 ICML，实际年份、格式与投稿日期后续核验。

## 三条可被否定的主张

- A：在学生相关状态上，不接收新增条件的老师存在可测量的质量收益与身份破坏冲突。以配对局部干预及同学生续采验证，不能只用 `g·d` 代替最终效果。
- B：有约束目标修正优于直接模仿、门控、加强条件损失、匹配梯度强度的弱 KD、匹配接受率的随机门控及仅条件方向。必须展示目标、有限拟合、最终生成三个层次。
- C：修正之外，老师一步起点与学生局部 rollout 有独立贡献。通过 H/O、T→S 与 S→S、固定最终 query time 的 `k=0/1/3`、计算量曲线验证。若只改善成本，只作效率主张。

“投影”“老师合成配对”“局部学生 rollout”各构件已有潜在近邻工作，不能独立据此主张首创。原文中的 CoDi、Diffusion Self-Distillation、HPSD、PDMD、DiffusionOPSD 等名称与链接要逐项核验版本、时间、真实方法和复现实装；未核验时只列候选文献，不能支持 novelty 宣言。

## 数据与两类训练分支

老师先生成完整目标 `x0T~pT(x|b)`，从该视频提取参考 `c=h(x0T)`。不能假设老师可随机命中外部指定人物。优先使用目标时间窗口之外的帧作参考。配对分支每次独立重新加噪 `z=αx0T+σε`，使用该状态下正确的原生训练目标。

混合分支：先抽最终监督时间 `tq`，在有效离散时间网格上向较高噪声方向安排 `T` 一步和 `S` 的 `k` 步，默认 `k=1`；在起点对老师视频重新加噪，`T→S^k` 到达 `tq`，轨迹整体停止梯度。到达后重新查询双方，不能复用最初噪声作为新状态正确标签。`c` 在整条局部轨迹固定。

完整学生分支 O：从部署所用纯噪声初始分布出发，由当前学生完整 rollout 至同一 `tq`，其余步骤及目标规则与 H 相同。不把重新加噪的短学生路径称作完整学生 rollout。

`T→S` 与 `S→S` 的起点消融：同一个重新加噪状态、同样总步数、同一 `tq`，只替换第一步执行者。它与 H/O 问题不同，需分开命名。

所有状态来源比较使用共同有效 `tq` 支持集、相同 scheduler、对应实际 σ/log-SNR、相同 query-time 分布和推理随机数。`k` 变化只改前缀长度与起点，不能顺带改变监督难度。不同步数需从同一个预先注册的主离散网格选点，记录每个实际 timestep，而非把 step index 当连续物理时间。

## 损失与归因

定义 `Lshared = Lpair + λc,pair Lc,pair + λc,q Lc,q`。`Lc,q` 在在线 query 状态的学生干净预测计算；只有存在该分支的方法才有此项。P 仅有 `Lpair+λc,pair Lc,pair`。H0/H1/H2/O0/O1/C-H/C-O 使用相同公共在线损失设计、mask、权重、预处理与 query-time 规则。这里的拆分使“在线身份损失本身”的替代解释可检验，不能悄悄让 H2 获得额外公共损失。

H0/H1/H2/O0/O1 再加 `λKD LKD`，C-H/C-O 精确置 `λKD=0`。H0/O0 原始目标，H1 条件门控，H2/O1 受约束目标修正。各方法自己的训练轨迹随模型变化，因此 C-H 与 H2 保证算法和采样协议对齐；若需要“完全相同数值状态”的局部因果分析，另用冻结并共享的 query-state cache。

所有方法可训练模块、优化器、batch、累积、精度、checkpoint 选择与开发调参次数匹配。LoRA rank 16/alpha 32、学习率 `1e-5`、200/1000/3000 更新仅为起始建议，不是已确定最优值。

## 主实验与规模

保留 S0 加八种训练方法 P/H0/H1/H2/O0/O1/C-H/C-O，每种正式训练 3 个独立 seed。S0 是同一冻结起点，不能把重复评测称为 3 个训练 seed。完整矩阵见 [experiment_matrix.csv](experiment_matrix.csv)。

正式外测建议每域 100 身份 × 4 提示词 × 2 生成 seed，两域共 1,600 视频/检查点；八方法 × 三训练 seed 共 38,400，加 S0 的 1,600，共 **40,000 主测视频的建议预算**。这不包括开发、消融、额外权衡操作点、局部干预、人工评测与第二平台；当前已执行数量为 0。预算需先测完整训练更新和完整推理成本，再由项目使用者冻结。

训练视频建议有效量 128/2,048/8,192；数据效率子集 `512⊂2,048⊂8,192`；合成开发及机制测试各 256，最小开发 32；外部开发每域 32 身份。二维机制实验建议 20,000 训练/10,000 测试、5 个训练 seed。详细划分与有效单位见 [data_protocol.md](data_protocol.md)。

## 研究判断

H2≈P：收缩为合成配对收益；H2≈C-H：在线条件损失解释；H2≈弱 KD：较弱蒸馏解释；H2≈仅条件方向：老师方向缺乏增量价值；H2≈O1：混合路径仅可主张成本/效率。只有老师前缀时有效、视频静止、外部评价器无收益、失败率升高均不得宣称研究成功。按证据缩小主张；不为达到投稿目标伪造结果或选择性省略对照。

预算口径补充：40,000 仅覆盖每个方法/训练seed的一个开发集选定 checkpoint、一个冻结推理操作点及 S0 的一套评测。如果 update-matched 与 compute-matched 对应不同 checkpoint，并都进行全量外测，应分别增加生成与评价预算；额外操作点、性能曲线、消融和重试也不在这 40,000 内。不能同时宣称 40,000 已覆盖两套全量对照。


目标归因还必须保留 **radius-only**：对原始老师方向采用相同半径裁剪但不投影，并单独设置半径匹配的实际门控，以区分 trust-radius 与投影/实际检查的作用。主 H1 仍是对原始 yT 的实际条件门控，定义不随此消融改变。
