# 评价、统计与测试冻结协议

三任务范围修订：正式任务为T1身份视频、T2 Canny图像、T3人体姿态图像，见 [three_task_protocol.md](three_task_protocol.md)。本文件原有视频/身份/帧数和40,000视频细节描述T1；图像任务按三任务契约执行，不能套用人脸检测或按视频身份分组来评图像边缘/姿态。

状态：待执行。主测试学生从部署噪声分布独立完整生成，只输入外部参考图、文本和新噪声。不得提供老师前缀、由老师续采或把合成训练身份当外部泛化结果。所有模型用同一预注册推理步数、scheduler、分辨率、时长、CFG 与条件强度；如条件强度是实验轴，先在开发阶段冻结操作点。

## 测试冻结

冻结对象：外部身份与参考 ID、4 个动作提示词、每例两个 inference seed、model/checkpoint 选择规则、primary/secondary metrics、阈值、允许缺失、重试规则、非劣界、统计脚本与人评样本。写入协议 SHA 和只读 case manifest；每个 case 预先有输出槽位。方法配置和 checkpoint 均只看开发集确定。

测试后修改方法、过滤、阈值或挑操作点，需要新确认集；否则标探索性，不写成预注册确认。独立评价模型的预处理和阈值不能根据待比较方法各自调整。研究者若已查看测试输出，应在 audit log 记录暴露时间及后续决策。

正式主测建议 `2域×100身份×4文本×2推理seed=1,600/检查点`。八方法各 3 个训练 seed，S0 1 个冻结起点，共 40,000 条计划生成；主测还没有执行。预算缩减可先每域 50 身份，并在首次测试前重新冻结，不以看结果删难身份。

## 身份与失效

训练身份代理与评价识别器使用独立权重/实现，候选为可微 ArcFace 训练、独立 AdaFace 评价；实际版本和适配需核验。不能用 VBench 主体一致性代替与参考身份的匹配。

默认建议每视频均匀采样 16 个生成帧。身份通过阈值在外部开发集用明确校准任务固定，至少记录真实匹配/非匹配分布、阈值与误差率；不编造通用余弦阈值。建议视频通过规则为 ≥90% 预定评价帧同时有效检测且身份匹配。检测失败、解码失败、人物替换和崩坏帧均在分母内；不能只计算成功检测帧。固定首帧或非生成区域按事先 mask 排除，不因生成结果差临时排除。

连续身份相似度同时报告覆盖率及按失败赋值的无条件统计（赋值规则预注册；如 cosine 指标须声明有效范围与失败最差值），可附成功检测条件下统计作诊断，但不能替代总体结果。人物背脸/遮挡的压力集单独报告再出现后的恢复率，主协议对可评价帧的先验定义需固定。

## 指标族与主张

| 维度 | 必须分开的测量 |
|---|---|
| 身份 | 独立识别器相似度、身份视频通过率、跨帧身份跳变、人脸检测覆盖率 |
| 图像/视频质量 | 已固定的成像/审美指标、运动平滑、闪烁、主体稳定、严重伪影 |
| 动作与文本 | 指定动作完成率、文本匹配，静止/重复和动作失败率 |
| 多样性与条件使用 | 固定噪声换身份的响应；固定身份换噪声的身份保持、运动与外观变化 |
| 人工 | 质量偏好、身份保持、动作完成，三问独立作答 |
| 成本 | 有效更新/样本数、完整训练时间与计算量、峰值内存、每视频推理成本 |

VBench 只使用实际支持当前自定义数据的维度，固定版本、权重与预处理。不随测试表现选择有利维度或临时综合权重。预先指定一个主要质量终点、一个身份终点及动作非劣约束；确切指标与非劣界在开发阶段定，不用临时总分掩盖质量/控制 tradeoff。

主结论要求主要质量改善，同时身份和动作的预设非劣条件成立，并完整报告静止复制、人物替换、检测/解码失败。按两个外部域分别报告，再给等权域平均；不能按样本数或成功检测数重加权。

## 训练与推理公平

报告两个训练视角：①相同有效 optimizer updates 和已见样本数；②相同完整训练计算预算。完整成本含 rollout、teacher query、VAE、身份梯度和回溯检查。C-H/C-O 无 KD 时按真实成本报告，不伪装与 H2 等成本。compute matched 通过预注册预算下各方法可达到的 checkpoint 比较；update matched 通过共同更新里程碑比较，不强行称一个 checkpoint 同时双匹配。

全部方法相同训练模块、优化器及开发调参预算；先测 5 次预热＋20 次完整更新的建议成本配置。硬件、精度、吞吐、计时同步、内存和统计区间都记录。部署推理配置严格一致，额外步数或不同条件强度作为单独曲线，不能混入主表。

## 两种不确定性，分开计算

**训练 seed 不确定性**：正式训练方法各 3 个独立 train seed，公开每 seed 值、三 seed 均值与 SD；S0 为固定起点，写 `train_seed=NA`。n=3 的 SD/区间反映有限训练复现，不因海量视频就变成精确训练分布估计。

**评价抽样不确定性**：在每个外部域内，按 identity cluster 有放回重采样，保留该身份的所有提示词、推理 seed、方法及可用训练 seed 的配对结构。每次对同一组重采身份算配对方法差，再按预先规则聚合固定的 3 个训练 seed；建议 bootstrap 10,000 次，报告 95% CI，明确这是给定这几个训练 seed 的 identity 抽样不确定性。不能把每帧/每视频当独立，也不能将该 CI 解释为训练 seed 不确定性。

训练 seed 之间是否配对需依据 seed block 的实际设计；同一数字并不自动证明独立训练噪声可配对。可补充两层 hierarchical bootstrap 作为探索性分析，但 n=3 的限制仍要说明。支持多个主比较时预注册比较族与多重校正或同时区间；未预注册的额外比较标探索性，不随显著性删列。

局部机制数据按真正独立来源（原始视频/身份簇或 toy 样本）聚类，不把同 query 的多个分支当独立样本。成对共享噪声与续采随机数，使局部干预差异可辨认。

## 人工评价建议

200 个预选配对案例，两域各 100；分别比较 H2 vs P、H2 vs O1、H2 vs H0；每对 3 位评者，共 1,800 次配对展示、5,400 分项判断。案例在三个 train seed 间平衡分配，固定 seed/文本，左右随机且盲化方法名，允许平局。公开选样、随机化、量表、培训、排除评者规则、一致性和匿名汇总；不发消息招募或购买服务，除非用户已授权相应外部行动。人工案例不从最佳输出挑选。

## 重试、缺失与结果导出

基础设施失败（如明确的磁盘/进程故障）可按固定次数、同 config 同 seed 重试，保留全部尝试；生成/检测/动作失败属于方法结果不能换 seed 重试。重试未解决的预定输出槽位写 `missing` 与原因，主分母不自动缩小。若某质量指标对失败视频不可定义，同时报告覆盖率、预注册失败处理及敏感性分析，不凭空填“正常”质量分数。

一条 per-video 结果保留 `case_id,domain,identity_cluster_id,prompt_id,method,train_seed,inference_seed,checkpoint_sha,video_sha256,status,failure_flags` 和每项 metric value/validity；一条 per-frame 结果保留 frame index、mask、检测与匹配标记。汇总由脚本从原始记录复算，人工抄表不作为唯一证据。共同 run 元数据及检查见 [gates_and_evidence.md](gates_and_evidence.md)。

预算口径补充：40,000 仅覆盖每个方法/训练seed的一个开发集选定 checkpoint、一个冻结推理操作点及 S0 的一套评测。如果 update-matched 与 compute-matched 对应不同 checkpoint，并都进行全量外测，应分别增加生成与评价预算；额外操作点、性能曲线、消融和重试也不在这 40,000 内。不能同时宣称 40,000 已覆盖两套全量对照。
