# 三个正式任务：共同假设与独立证据

本次修订把研究范围明确为 T1、T2、T3 三个条件生成任务。三个任务必须出现在主启动 prompt、派工表、实验登记和论文结果清单中，不能仅完成视频后把另两个静默降为可选项。允许某任务得到负结果；资源未到位时标未执行，不能写三任务验证完成。二维 toy 是机制诊断，第二视频架构是 T1 的架构扩展，均不额外计为一个主任务。

| ID | 正式任务 | 新增条件 c | 老师 → 已有条件学生候选 | 主要条件维度 |
|---|---|---|---|---|
| T1 | 身份保持视频生成 | 外部人物参考图 | Wan2.1-T2V-1.3B → Concat-ID-Wan-AdaLN | 身份语义与跨帧保持 |
| T2 | Canny 边缘控制图像生成 | 目标图像的 Canny 边缘图 | 与条件权重匹配的 SD1.5 文本图像老师 → ControlNet 1.1 Canny 学生 | 密集轮廓与空间布局 |
| T3 | 人体姿态控制图像生成 | 单人人体骨架/关节点图 | 同一 SD1.5 文本图像老师 → ControlNet 1.1 OpenPose 学生 | 稀疏人体关节点与肢体结构 |

T2/T3 的官方候选分别为 `lllyasviel/control_v11p_sd15_canny`、`lllyasviel/control_v11p_sd15_openpose`。官方模型卡提供它们与 SD1.5 的使用示例，但精确底座 revision、权重、VAE、scheduler、许可、梯度和训练适配仍须本地 W0 核验。不能把不同 SD1.5 衍生 checkpoint 当作天然完全匹配。T2/T3 复用同一基础架构能控制工程变量，不构成两个独立架构验证，也不能据此宣称适用所有条件。

## 三任务共同执行

每个任务均保留冻结文本老师 `T(z,t,b)` 与带新增条件的现成学生 `S(z,t,b,c)`。由老师先生成完整视频/图像，离线提取 `c=h(xT)`，每次更新独立重新加噪；混合分支固定最终监督时间，再执行老师一步、学生 k 步、在新状态查询并构造停止梯度的目标。目标修正仍遵守生成 mask、固定 batch 分母、有限近零梯度实际回溯与无效样本拒绝规则，详见 prediction_and_target_contract.md。

每任务独立运行 S0 + P/H0/H1/H2/O0/O1/C-H/C-O，正式训练建议三 seed；不得让新增任务只跑 H2 而省略归因对照。按任务分别通过 W0 兼容/成本、W1 局部干预/最小训练、W2–W3 开发筛选/归因、W4 冻结正式评价。不要求先跑完 T1 才准备 T2/T3；CPU 准备可并行，GPU 作业按租约排队。某任务老师方向无收益时，对该任务做诊断并报告负结果，不自动取消其余任务。

A/B/C 三条主张按 `task_id` 独立判断：老师方向是否存在质量—条件冲突；目标修正是否超出弱KD/在线条件损失等解释；混合轨迹是否独立贡献质量或成本。跨任务汇总为支持/部分支持/不支持的证据表，禁止将身份余弦、边缘 F1 和姿态 OKS 直接平均成一个总分。半径、容差、条件损失权重、代理可靠噪声区间和阈值各任务在开发集校准，不能直接照搬视频值。

运行元数据增加必需 `task_id`，实际目录采用 `runs/<task_id>/<run_id>/`、独立数据 manifest、任务 gate 和预算；代码共享文件仍只由唯一 owner 修改。历史路径若存在只记录不搬移，不能因新目录规范重启旧作业。当前交接包没有任何实际 run，全部实验未执行。

## T1：身份保持视频

保留已有数据、外窗参考、独立识别器、跨帧/动作/静止失败及按身份聚类统计的协议。参考在目标窗外优先，固定输入帧排除评分。第二视频架构 CogVideoX/ConsisID 是可选的 T1 架构复核；不能拿第二模型冒充第三个条件任务。

## T2：Canny 边缘控制图像

数据：老师文本生成图像后提取固定 Canny 条件，记录阈值、颜色/尺寸与边缘细化规则。外部条件来自来源和许可可核验的自然图像，原图、近重复和同源变体分组划分；不要仅用老师训练图的边缘作外测。如复用 T3 老师图，必须保持全局源图分组和各自有效样本 manifest，不能把重用图像算成新增独立样本。

训练误差：对 `Decode(y)` 使用可微 soft-edge（如经校准的 Sobel 平滑梯度幅值）与固定目标边缘比较。硬 Canny、阈值、非极大抑制可用于离线条件生成，但不能直接作为回传链路。soft-edge 不是 Canny 的精确等价物，需用局部干预检验其方向与硬指标是否一致，记录纹理/细边缘/粗边缘偏差。

评价：独立固定的硬边缘提取器，报告带开发集固定像素容差的边缘 precision/recall/F1、双向边缘距离（声明像素或图像对角线归一化单位）、图像质量、文本符合、失败和同条件多样性。图像按输入规定画布映射后直接比较，禁止根据生成结果再拟合对齐。空边缘/纯线稿、过度锐化、将条件线条直接画到输出等均单独记录，不能只凭边缘得分判成功。统计按源图/近重复组聚类，不能把同一图的多个文本/seed当独立样本。

## T3：单人人体姿态控制图像

数据：老师先生成单人、主体完整可见的图像，再离线提取 keypoints、置信度、可见性和渲染骨架。先从 OpenPose body 开始，不同时引入人手/面部关键点；保存数值点与渲染图，两者同源。过滤多人、截肢/出界、关节不可辨、姿态标签错误，保留过滤前后数量与原因。外部姿态候选为许可核验的 COCO person-keypoint 来源及保留的姿态组合；防止原图、同人物与近姿态模板跨训练/调参/确认集泄漏，明确姿态相似度分组规则。

训练误差：冻结可微 PyTorch 姿态网络（候选 HRNet）的原始 heatmap forward，对固定输入可见关节的目标 Gaussian heatmap 比较，可加 soft-argmax 坐标项。网络权重冻结且 eval，但对解码图像保留梯度；默认推理 API 中的 NumPy/硬 argmax/ONNX 后处理不能放进目标梯度。检测/裁剪坐标可 detached 决定，并在一次目标构造及 before/after 检查中固定；不能随着候选目标改匹配对象以虚增接受率。可见性分母由输入目标决定，不由生成结果选择。若代理在给定噪声下不可靠，应拒绝KD/限制预注册query区间并保留计数，不能伪称有可靠姿态梯度。

评价：使用与训练代理不同权重的冻结姿态估计器，优先选择不同架构，报告 PCK 与 OKS（各自定义、阈值、坐标尺度及关键点 schema 固定），同时报告真实感、文本符合、人体/肢体伪影、检测失败和多样性。没有检出预期人体、关节缺失和额外人物不能从分母删除。主指标不能先对输出做 Procrustes/缩放平移配准再评分；输入规定的裁剪/缩放映射允许但必须事前固定。

COCO17 与 OpenPose18 等 schema 不可按张量索引硬配。先锁定关节名称、左右、连接边和目标画布；需要 neck 时明示由双肩中点构造或排除该点，不新增假标签；仅对可对应且输入有效的关节计算损失/指标。固定canvas和目标bbox用于归一化，不用模型输出自己的bbox消除位置误差。统计按源图/人物簇以及预注册近姿态组处理依赖；若人物标识不可得，写明可核验分组及残余相关性，不能声称已完成身份隔离。

## 建议规模与预算

T1 沿用 128/2048/8192 条有效老师视频和 40,000 主测视频的单检查点/操作点预算。T2/T3 各从 128 张 smoke、2048 张开发筛选至建议 8192 张有效训练图、512 张开发图、500 个外部测试条件。正式每条件 2 个兼容文本 × 2 推理seed，即 2000 图/检查点；八训练方法×三训练seed+S0=25检查点，故各任务 50,000 主测图像，两任务共 100,000 张。500 指外部条件数，不是所有检查点加起来的生成张数。

上述是范围规划，不是新增算力授权；完整成本须每任务实测，图像与视频成本分别估算。额外 update/compute 对照检查点、开发、消融、老师数据生成、独立评价与重试另计。预算不足时先冻结缩小的三任务协议并披露统计能力损失，不能保留“三任务完成”标题而只跑一个任务，也不为达标自行采购。

## 论文与完成标准

论文必须逐任务列数据来源、老师/学生版本、条件误差、独立指标、对照、预算、训练seed、失败和结果状态。三个任务均需完整登记；完成研究可得正/负结论，但某任务未执行不能写三任务实验完成。三任务中只有一部分有效时按实际范围收窄主张并保留负结果。现阶段所有结果为 PENDING。
