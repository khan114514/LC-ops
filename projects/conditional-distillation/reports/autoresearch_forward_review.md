# AutoResearch 独立前向审查

日期：2026-10-26。审查对象是本次更新的提示词、技能、规范与模板。独立审查者只读检查，未修改被审文件。以下为审查意见的整理；不是训练实现审查、实验结果或投稿资格认证。

## 场景与修复

| 场景 | 预期行为与复核结果 |
|---|---|
| 尚缺GPU、预算或模型访问 | 明确缺项，继续不依赖缺项的已授权工作；不能把结构检查或待实验初稿当作研究完成。 |
| 某候选在某任务出现科学阴性 | 排除实现故障，按事前规则独立复核后关闭有证据支持的分支；后继保持未运行，其余候选与任务继续。 |
| 仅剩在途训练或worker | 总控验收真实作业、有限等待并恢复下游，不能在启动或派工后宣称完成。 |
| 多任务及辅助toy | 正式run归属T1/T2/T3；TOY单独标记且不代替真实证据；跨任务非实验派工用task_ids。 |
| 阶段预算耗尽且仍INCONCLUSIVE | 曾缺明确出口，现已补齐：先检查事前允许的重分配；不能合理继续则PARTIAL_BUDGET_STOP，保留不确定性、余额和未运行范围。已有授权内冻结阶段预算不需重复请求授权。 |
| 完全非OPD候选的开发证据更好 | 可依据问题契合、新颖性主源、实用性和成本选中；正式测试前冻结自己的机制、必要对照及活动矩阵。改选方法本身不算缩水，单任务pilot不证明三任务有效。 |
| 新方法不需要可微条件代理或老师目标数据 | 曾有旧主prompt的通用措辞阻断，现已限定为按候选适用性检查；N/A需有理由。真实更新、保存/重载、独立生成和评价要求仍保留。 |

## 最终复核结论

独立审查者确认：先前关于非OPD路线的P2问题已关闭。主启动提示词、G0与执行契约已采用一致的候选适用性口径。原八方法、投影G1、条件梯度或固定老师数据不再成为所有候选的通用门槛；新的候选仍须完成测试前冻结的正式协议与独立QA。

独立审查者同时确认，阶段预算耗尽但证据不足的场景有明确退出状态，不能冒称阴性证明或完整研究完成。上述文本场景复核通过。

范围限制：未执行真实实验，未审训练代码或成本脚本，未验证候选新颖性、实用效果、GPU兼容性、统计功效、人评或ICML录用可能。辅助代码与分发包验证另见 [验证记录](autoresearch_validation.json)。
