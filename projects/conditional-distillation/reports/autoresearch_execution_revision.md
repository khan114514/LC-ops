# AutoResearch 执行修订

日期：2026-10-26。适用普通开放研究；本次修复交接材料和辅助代码，不启动实验。

主启动入口仍为 [00_START_HERE_CN.md](../prompts/00_START_HERE_CN.md)。新增 [统一执行契约](../specs/execution_contract.md)，同步共享/角色 prompts、总控和相关技能、三任务/gate/机制规范、派工与完成报告模板、使用指南。没有改动原始研究文本、论文算法、历史实验或历史审查报告。

修复内容：

- 草稿完成、派工和训练启动不再是整体研究结束条件；明确验收、回收、等待与授权内下游推进。
- G1 科学阴性可以按事前规则独立复核后关闭；跳过的后继保持未运行，不冒充全量矩阵完成。
- 三任务统一新 run 路径，辅助 TOY 独立标签和目录；跨任务非实验派工的 task_id/task_ids 明确。
- 成本脚本增加按任务、方法、配置和硬件的完整训练成本表。缺测/缺行保持未知，不回退单一方法耗时；旧 CLI 仍作明确的简化估算。
- 完整协议、阴性提前关闭、缩水协议、预算停止、外部阻断、暂停和中断分别报告。独立 QA 实质问题需修复并复核。
- 技能安装同步包含新契约的引用资源；源码清单、ZIP 和 SHA-256 一起更新。

验证详情见 [autoresearch_validation.json](autoresearch_validation.json) 和 [独立前向审查](autoresearch_forward_review.md)。这些是辅助代码与文档流程验证，不能证明模型兼容、GPU训练、生成质量、统计功效或人评已完成。模板中的资源与实测成本继续为空，研究状态保持未启动。

追加方法开放范围：原OPD/投影/混合轨迹与八方法矩阵降为初始家族模板；新增第19份prompt（编号18）、方法搜索/开发筛选/选择规范、候选卡和总控状态。最终以测试前冻结的相关矩阵为完整协议，候选选择兼顾新颖性主源、实测实用性和证据潜力，论文按最终方法重写并汇总淘汰与负结果。另补诊断阶段预算耗尽但结论不确定的退出路径，修正已有总预算下无需再次请用户冻结阶段预算。
