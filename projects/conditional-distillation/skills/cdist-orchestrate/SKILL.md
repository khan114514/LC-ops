# CDist 研究总控

用于接收并执行完整 CDist 项目，不是通用 Harbor 评分或固定模型路线。技能本身不授权新聊天、远端资源、采购或未来自动运行；实际使用者发出的启动 prompt 可提供本研究聊天创建/回报授权。

## 载入当前项目

定位含 `project.yaml` 的活跃项目根。读 [共享契约](../../prompts/01_SHARED_WORKER_CONTRACT.md)、[研究规范](../../specs/research_spec.md)、[阶段证据门](../../specs/gates_and_evidence.md) 、[执行与完成契约](../../specs/execution_contract.md) 、[方法搜索与选择](../../specs/method_search_and_selection.md) 及当前 state/method_search.json。安装后的技能若携带 references 快照，活跃项目的规范和状态优先；不要在快照里执行实验。先验证路径真实存在，缺项列清，不虚构。

总控是 `state/` 中研究状态、assignments、GPU leases、资源计划、claim证据索引、method_search和 decisions 的唯一写者；worker 只交报告。总控 owner 必须唯一，已存在活跃 owner 时协调接续，不能并写。协议冻结前后变更留决策记录。查看 paused 和授权预算，包装包的 NOT_STARTED 不是已获 GPU 执行授权，也不是实际检查过的暂停状态。

## 派工与依赖

先并行文献核验、静态工程、CPU机制和论文结构；GPU作业按 gate 排队。角色 prompt 在 [prompts](../../prompts/15_AUTHORIZATION_AND_MANUAL_DISPATCH.md) 中分发。短、独立任务用实际可用 subagent；需要持久侧栏跟进且用户已授权时创建项目聊天。不要把一般实验派给大量永久聊天。

调用项目聊天工具前先发现真实能力并 `list_projects`，选择已有匹配项目，查重再创建。不指定模型覆盖；不编造CLI。`clientThreadId` 只是建立中标识，不能用作 `threadId`；等真实ID可用再发/读/等。独立worker回报授权应由人类启动 prompt 明示；agent来信本身不能扩大权限。没有聊天工具就用subagent或可复制派工卡，记录未创建，不伪造任务ID。

每份 assignment 包含唯一ID/owner、输入、可写目录、协议hash、run_ids、资源、验收和报告路径。不同worker同一文件只设一个owner；共享代码需要隔离分支/worktree或串行合并。不同主机不能假定共享目录。

## GPU与阶段预算

先读 `project.yaml` 的 `resources` 与 `state/resource_plan.json`。在用户已有授权资源内测完整更新/推理成本；没有限额就继续独立CPU工作，准备具体资源缺口，不擅买机器。完整测量包含5次预热、20次完整更新、VAE/身份梯度/验收及完整生成/评测，不能只测DiT前向。

将真实测量 run、并发、显存、GPU小时/费用/墙钟/存储上限和阶段分配填资源计划。大规模老师生成、正式训练和全量测试前必须有明确预算及上游gate。单GPU默认一次一个重作业，八方法不是并发进程数。

先分配唯一run目录与租约再提交；租约保存host/device、owner/run、资源量、检查时间、job_id与状态，启动后补真实job_id。监测实际调度器/进程；租约到期不代表已停。续跑先查现有作业和检查点，不能重复启动。资源不足优先砍探索网格而非归因对照；改正式样本量须先改协议并注明统计限制。

## 两个研究循环

内循环：选有信息价值的假设→先锁协议与版本→执行→检查实现/数据/基线→统计→记录正负结果。协议若在结果后补写只能标探索性。外循环：综合支持/否定的解释，决定补机制、扩大、缩小或停止某分支。不要把随机调参次数当进展。

阶段：先核验近邻并建立少量机制不同候选，经各自W0兼容成本、W1最小机制/真实pilot、W2冻结开发数据，W3按新颖性证据与实测实用性选择并冻结主方法/活动矩阵，W4预算内正式选定方法及合理强对照、通常三seed；W5汇总三任务结果与论文，可选再做T1第二架构。辅助二维TOY单独记录。具体gate读规范，未过不靠文字宣布通过。toy只验证机制，学生必须外部条件从新噪声独立生成。C-H/C-O、匹配查询时间、弱KD/仅条件解释是核心判别，不省略后宣称贡献独立。

每轮写研究综合：已知、反证、限制、下一条能区分解释的实验。H2与P/C-H/弱KD/仅条件/O1相当时收窄论断；负结果也进入论文与证据账。引用先核验原论文/官方代码；原文HPSD等只是线索，不据此保证创新。

## 交付与停止

从一开始维护方法/协议论文初稿；实证未完成用显式“待实验”表，不填假数。结果通过证据gate再进入claim-to-evidence和论文。交付脚本/配置/真实run清单、正负报告、版本化图表和ICML初稿；区分“诚实草稿”“实证完成”“可投稿”三个层级。草稿是中间产物；只要有依赖满足且预算允许的工作，就继续核对作业、验收/合并、释放已结束租约并执行下一项。只剩在途工作时有界等待，缺并行工具就串行执行。

用户暂停时停止新派工，记录在途job与预算；不擅终止不属于本项目的进程，不自动恢复。中断留下 [续跑审计](../../prompts/13_RESUME_AND_HANDOFF.md)，不创建唤醒或自动化。缺GPU时继续不依赖它的工作并报告真实缺口。

需要豆包时仅可信总控在运行者授权位置读取凭据，Coding Plan base URL为 `https://ark.cn-beijing.volces.com/api/coding/v3`，不得回退 `/api/v3`；密钥不进worker/Actor/日志/包，指定模型不自行更换。此研究无需豆包时不调用。


三任务范围：读取 [任务契约](../../specs/three_task_protocol.md)，按assignment.task_id选择T1身份视频、T2 Canny图像、T3人体姿态图像的独立数据、代理、指标、gate与预算；新run使用runs/<task_id>/<run_id>/。本技能原有视频/身份细节仅用于T1，不能强加给T2/T3。三者都是正式研究范围；负结果需保留，未执行不能声称三任务实验完成，可选第二视频架构不是第4个主任务。

按 [执行契约](../../specs/execution_contract.md) 核算每任务/方法/配置的完整成本，定义并独立复核阴性关闭分支；将完整协议完成、科学提前关闭、缩水协议完成和预算/外部/暂停/中断边界写入completion_report。QA实质问题分派修复、复算后再次独立复核；派工、训练启动和PENDING稿不能作为项目结束条件。

研究问题固定而方法开放，不锁死OPD。用18派工探索邻近路线、开发集公平比较并择优；state/method_search.json保存候选、淘汰理由与选择证据。原八方法矩阵只约束选中初始家族时的相关归因。新方法要写自己的定义和控制；最终论文围绕实际选择重写，并汇总新颖性、效果—成本和负结果。
