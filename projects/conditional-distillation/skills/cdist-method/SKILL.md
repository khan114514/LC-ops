# 方法实现

先定位当前活跃项目根，读取 [研究定义](../../specs/research_spec.md) 与 [预测及目标契约](../../specs/prediction_and_target_contract.md)。阶段、资源与运行状态以活跃项目为准；安装快照不覆盖已冻结的新协议。本技能用于实现研究方法，不自动启动整个预算或其它研究工作流。

## 不可省略的决定

- 老师不接新增身份条件，可接文本；冻结老师及身份代理参数。学生从已有条件能力 S0 开始。
- 先采最终 `tq`，再安排 `T一步→S^k` 前缀，默认 k=1。全程固定 c，rollout stopgrad；到新状态重新查询，禁止复用初始 ε 作标签。k 与状态来源比较保持共同 tq 支持及实际 σ/log-SNR。
- O 是从部署纯噪声出发的完整学生路径；同 re-noised 起点的 `T→S/S→S` 是另一个消融。
- 比较同一生成区域、同状态/时间和真实可逆参数化。区分标准 v 与一般 flow，按实际 scheduler 导数映射；VAE不兼容时先解决映射。边界不可逆不硬除。
- 条件梯度穿过可微 VAE/特征与裁剪；teacher/rollout/最终 target 停止梯度，`create_graph=False`。公共在线条件 loss 保留到学生的一阶训练图。参考 token、固定首帧和非生成区域全程 mask。
- 投影按每样本；一阶半空间投影→注册半径→`1、1/2、1/4` 回溯实际代理检查。有限零梯度只尝试裁剪原始方向并实际检查；梯度非有限、代理无效或 mask 空直接拒绝 KD。全 batch 拒绝仍保留有效公共更新。以固定总 B 作 KD 分母并记录剂量。

## 实现与验收

在项目实际模型代码中做最小 adapter，保留精确 revision/config。优先完成 roundtrip、边界、非生成 mask、teacher无梯度、学生梯度、零/NaN梯度、部分/全拒绝检查和一个真实 batch 的完整更新，再扩大。实现上详尽规则集中在契约，避免自行创造另一套默认。

损失与 P/H0/H1/H2/O0/O1/C-H/C-O 定义依研究规范；C-H/C-O 只移除 KD，不能顺带取消在线条件监督。所有方法共享可训练模块、公共权重和调参预算。适配失败或缺少模型时报告可观察阻塞和已完成检查，不能生成虚构“训练成功”。

输出到当前任务自己的 artifact 目录：adapter/训练代码、resolved config、真实兼容测试、每样本目标诊断、完整更新成本、独立纯噪声推理样例及 run manifest。元数据依 [证据契约](../../specs/gates_and_evidence.md)。投影和目标检查不等于参数更新或最终视频的身份保证；不得写入这种结论。


三任务范围：读取 [任务契约](../../specs/three_task_protocol.md)，按assignment.task_id选择T1身份视频、T2 Canny图像、T3人体姿态图像的独立数据、代理、指标、gate与预算；新run使用runs/<task_id>/<run_id>/。本技能原有视频/身份细节仅用于T1，不能强加给T2/T3。三者都是正式研究范围；负结果需保留，未执行不能声称三任务实验完成，可选第二视频架构不是第4个主任务。
