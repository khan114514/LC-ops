# 数据制作与冻结

方法范围：先读 [方法搜索与选择](../../specs/method_search_and_selection.md) 和当前候选/选定协议。本文涉及的OPD、H/O/C、投影/局部轨迹是初始家族要求，不是所有候选必用算法；其它路线按其冻结定义与控制执行，共同证据边界不变。

读取 [数据协议](../../specs/data_protocol.md)，需要任务范围时读 [研究定义](../../specs/research_spec.md)。以活跃项目根的最新冻结协议为准，不用安装快照覆盖新版本。所有量为建议有效样本量，初始包无已执行数据。

## 数据处理

1. 核对实际模型来源/版本、数据来源与许可，建立 raw candidate manifest；失败生成也有ID。使用项目已授权资源，先测接受率与成本，再按有效量预算扩大。
2. 老师生成完整视频，提取该视频自己的参考身份。不能要求老师随机命中外部指定人物。优先目标窗口之外的参考帧，参考与目标分别编码；每次更新选一张，整条局部路径固定。
3. 记录解码、单人/切镜、身份、动作、静止重复、伪影过滤。按动作/姿态/质量分层人工抽查，保存全部候选、排除原因与数量漏斗；各训练方法共用同一数据版本。
4. 先以原视频、近重复连通分量和核验身份簇分组，再划分。相同分组不跨 train/dev/test；外部 dev/test 同样身份互斥。不能默认FFHQ每图不同人或公开元数据身份无误。
5. 冻结 source/许可索引、manifest与SHA、划分/去重脚本、过滤阈值、人工复核、嵌套512⊂2048⊂8192 ID、prompt与seed。发布受限原资产须依实际许可，通常交付下载/处理脚本和ID。

## 关键质量检查

一个完整老师视频才是基本独立样本；多裁剪、多窗口或多次加噪不增加视频/身份数。未核验的不同老师视频不能当同身份多动作配对。目标窗口内参考必须标记 overlap 并按协议屏蔽重叠帧身份 loss，单列消融。固定首帧和参考 token 不得进入生成区域 KD/身份评分。

“未见身份”仅指本次蒸馏训练和调参未使用，不能声明基础预训练从未见过。第二平台生成自己的老师配对，不能复用第一平台数据后称完整跨平台验证。

输出数据版本报告、可复算计数、划分与许可审查、参考窗口/编码检查、泄漏风险与未核验条目。按照 [证据契约](../../specs/gates_and_evidence.md) 写 run metadata；禁止把计划量写成已生成量、把未知身份关系写成已去重通过。


三任务范围：读取 [任务契约](../../specs/three_task_protocol.md)，按assignment.task_id选择T1身份视频、T2 Canny图像、T3人体姿态图像的独立数据、代理、指标、gate与预算；新run使用runs/<task_id>/<run_id>/。本技能原有视频/身份细节仅用于T1，不能强加给T2/T3。三者都是正式研究范围；负结果需保留，未执行不能声称三任务实验完成，可选第二视频架构不是第4个主任务。
