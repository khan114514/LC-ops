# Worker report 模板（不是实际完成报告）

- task_id / assignment_id / owner / allowed_paths：
- 读取的 protocol SHA / code SHA / config SHA / data version：
- 输入依赖及版本：
- 实际执行命令、job id、退出码和日志路径：
- 输出文件、检查点及哈希：
- 观察到的结果（区分实测、估算和推断）：
- 失败与反证：
- done gate 检查（PASS / FAIL / UNVERIFIED 及证据）：
- 需要总控接入的变更与后继任务：

不要在模板中预填 PASS 或实验数值；不要把凭据放进命令复现文本。
