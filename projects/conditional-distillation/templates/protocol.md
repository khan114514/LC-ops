task_id（T1/T2/T3；辅助机制为TOY）、ID、版本、锁定时间与 owner：
研究问题 / 可证伪预测：
CONFIRMATORY 或 EXPLORATORY：
方法、固定项与唯一变化项：
对照、训练与推理种子、数据/模型/配置版本：
最终 query time 的分布与匹配方式：
训练更新预算、实际计算预算、推理配置：
主要指标、单位、方向、估计量、训练 seed 与身份聚类层级：
身份与动作非劣界、失败定义、接受/拒绝规则（开发阶段固定）：
检查点/超参数选择规则和测试锁定：
成功、无效、故障、停止和缩小范围条件（事前定义最小证据量、不确定性、诊断预算、独立确认/复核；阴性关闭和未执行后继按execution_contract记录）：
原始输出位置、分析命令、所支撑 claim / figure：

锁定后保存 SHA 并在结果产生前提交版本。协议变化创建新版本，旧记录保持可追溯；没有 Git 时保存只追加的时间戳记录和内容哈希，不宣称等同独立预注册。
